## Prerequisites

| Tool | Version | Needed for |
|------|---------|------------|
| Docker + Docker Compose | current | The one-command stack |
| `uv` | current | Backend work outside Docker |
| Python | 3.14 | Backend work outside Docker |
| `bun` | 1.x | Frontend work outside Docker |
| Git | current | Cloning and contributing |

No PayPal, Clerk or LLM account is required to run Vizlify locally. The default
modes are mock/dev and are designed for exactly that.
